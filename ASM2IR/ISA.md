# Wave32

ISA для [приложения с волнами](../app.c), переписанного в [wave.s](wave.s).
Выбор команд основан на [LLVM IR](../app.ll) и [статистике второго задания](../LLVM_Pass/results/summary.md):
`call ← or` (25,350%) и сдвиги мотивируют `PACK/CELL`, `udiv ← mul` (6,341%) —
`MULDIV`, `br ← icmp` (4,503%) — условные переходы,
`load ← getelementptr` (3,436%) — `LD/ST` с адресацией `base + index`.
Проценты относятся к динамическим рёбрам использования операндов, а не времени.

## Машина и синтаксис

32 регистра `r0`–`r31` и 221184 слова памяти по 32 бита, изначально нулевые.
Адреса измеряются в словах. Одна команда на строку; разделители — пробелы/запятые,
метки — `name:`, комментарии — `#` или `;`. Регистр букв значим.
`d` — регистр назначения; остальные значения — регистры или константы
(десятичные либо `0x`, диапазон −2147483648…4294967295).
Источники читаются до записи назначения. Выполнение начинается с первой команды.

`wrap` оставляет младшие 32 бита, `s` трактует их как знаковое число.
Деление округляется к нулю; остаток имеет знак делимого. Нулевой делитель,
пара `INT32_MIN, -1` при делении/остатке и выход за память вызывают ошибку.

## Инструкции

| Команда | Действие |
|---|---|
| `MOV d, a` | `d = a` |
| `ADD d, a, b` | `d = wrap(a+b)` |
| `SUB d, a, b` | `d = wrap(a-b)` |
| `MUL d, a, b` | `d = wrap(a*b)` |
| `DIV d, a, b` | `d = s(a)/s(b)` |
| `REM d, a, b` | `d = s(a)%s(b)` |
| `MULDIV d, a, b, c` | `d = s(wrap(a*b))/s(c)` |
| `PACK d, a, b, c` | `d = 0xff000000 \| ((a&255)<<16) \| ((b&255)<<8) \| (c&255)` |
| `LD d, base, index` | `d = memory[wrap(base+index)]` |
| `ST base, index, value` | `memory[wrap(base+index)] = value` |
| `RAND d` | Следующее псевдослучайное число |
| `CELL x, y, c` | Четыре пикселя клетки цветом `c` |
| `FLUSH d` | Показать кадр; `d=1` для продолжения, иначе `0` |
| `JMP label` | Безусловный переход |
| `BEQ a, b, label` | Переход при `a == b` |
| `BNE a, b, label` | Переход при `a != b` |
| `BLT a, b, label` | Переход при `s(a) < s(b)` |
| `BLE a, b, label` | Переход при `s(a) <= s(b)` |
| `HALT` | Завершение; выход за последнюю команду также завершает программу |

`CELL`: `px=wrap(4*x+1)`, `py=wrap(4*y+1)`; порядок пикселей —
`(px,py)`, `(px+1,py)`, `(px,py+1)`, `(px+1,py+1)`, в пределах окна 1536 × 768.
`RAND`: состояние `v=wrap(1664525*v+1013904223)`, результат `v >> 1`;
начальное значение — `--seed` (1 по умолчанию).
`FLUSH` возвращает 0 при достижении `--frames` или закрытии окна;
`--frames 0` разрешён только с `--sdl` и снимает лимит.

В `wave.s` регистры `r0/r1/r2` хранят базы полей `previous/current/next`,
`r3` — номер кадра, `r4`–`r14` — временные значения, `r30` — результат `FLUSH`.
